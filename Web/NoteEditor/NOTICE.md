# Notes editor sources

The editor enhancement functions and Markdown renderer are adapted from the user's local personal_station project. Review that project's applicable license before distributing those adapted sources.

Third-party packages are pinned in pnpm-lock.yaml. Bundled JavaScript retains esbuild legal comments. Resources/NoteWeb/THIRD-PARTY-NOTICES.txt contains installed dependency licenses. Node.js is required only to rebuild assets, not to run the installed app.
