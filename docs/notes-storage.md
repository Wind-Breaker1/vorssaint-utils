# 笔记存储与索引

笔记、画板和附件保存在用户选择的目录，默认使用 iCloud Drive/Vorssaint/Notes。
全文和链接索引放在本机 `~/Library/Caches/<bundle id>/NotesIndexes`，按数据目录路径区分。
索引不参与 iCloud 同步，可以从笔记文件重建。

打开笔记窗口或应用回到前台时核对文件变化。未下载的 iCloud 占位文件保留已有索引并请求下载，
不会当作删除；读取、写入和迁移遇到未下载文件时提示等待，避免覆盖。文件版本冲突会报告错误。
已下载的新增、修改、删除会更新列表。普通保存只更新该笔记的摘要与链接；没有变化时不重置编辑器。

更改目录在后台复制、校验并重建本机索引，完成后切换保存位置。迁移期间暂时禁止编辑。
原目录保留，保存旧目录记录。设置页“更改目录”之后的“删除旧数据”按钮可手动删除旧目录及全部内容。
没有待清理的旧目录时按钮禁用。
旧目录记录跨重启保存，当前保存目录及其父子目录不能作为旧目录删除。

`Tests/NotesStorageIntegrationTests.sh` 与 `Tests/NotesStoreIntegrationTests.sh` 覆盖文件读写、搜索、
云端占位文件、索引回滚、连续保存、窗口搜索资源释放、后台迁移和手动清理。
真实 iCloud 双设备同步仍需设备验收；应用不实现跨设备自动正文合并。
