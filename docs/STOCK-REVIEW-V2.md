# 股票复盘工作台

工作台包含「成交记录」与「每日复盘」两页。

## 成交记录

- 手动录入、编辑、删除 A 股与场内 ETF 成交，也可导入、导出 CSV / TSV。
- 根据历史流水计算持仓数量、移动加权平均成本、已实现盈亏和手续费。
- 支持现金分红与份额调整记录。

## 每日复盘

- 按日历选择日期，记录市场观察、经验与改进、明日计划。
- 「行情」展示指数、市场指标、近三日行业领涨/领跌前五和连板天梯；支持手动获取行情。
- 左侧交易纪律默认只读，可切换编辑并自动保存。

## 数据

- 成交、复盘和市场快照按年保存在 `trades/`、`reviews/`、`market/` JSON 文件中；交易纪律保存在 `rules.json`。行情采集不会创建空白复盘记录。
- 可在应用设置中选择数据目录、迁移至空目录、恢复备份及配置自动行情采集。
- 应用在每次写入前备份数据，最近 30 份备份保留在 `backups/`。
- 选择 iCloud Drive 目录后由 macOS 同步；应用不提供独立云同步服务。

## 验证

运行 `./build.sh --test-suite=stock-review` 执行股票复盘测试。
