# 股票复盘第一版实施与验收清单

范围：A 股与场内 ETF；单人使用；用户选择本地或 iCloud Drive 数据目录；年度 JSON；从首笔成交计算；仅免费数据；无 AI、无券商下单、无独立云同步服务。

- [x] 3. 成交新增/编辑/删除、持仓、交易统计与自选。
- [x] 4. CSV/TSV（UTF-8/GB18030）导入预览、重复检查、导出与模板。
- [x] 5. 免费行情、K 线、涨停/跌停/炸板、行业/概念轮动、情绪读数、来源与缺失状态。
- [x] 6. 每日复盘、结构化计划与结果、关联成交。

## 打开与测试

1. 打开 `build/stage.noindex/Vorssaint (Developer).app`。
2. 设置 → 功能 → 个人工具，安装/启用「股票复盘」。新增功能默认关闭，不影响其他功能。
3. 设置 → 个人工具 → 股票复盘 →「打开股票复盘」。应用菜单也有「股票复盘」入口。
4. 进入「数据与设置」，选择 iCloud Drive 中专用于股票复盘的空目录。已有数据使用「打开数据目录」，搬家使用「迁移到空目录」；迁移保留原目录。
5. 点击「记一笔」，从最早一笔成交开始录入。编辑保存前会重新核算整个历史；缺少买入或卖超持仓时拒绝保存。
6. 「成交记录」→「导入 / 导出」，下载 CSV 表头模板，或导入券商导出的 CSV/TSV，核对预览后保存。
7. 「市场快照」选择最近已收盘日，点击「获取 / 补全当日数据」。确认涨停梯队、板块排名、情绪指标和来源状态。
8. 「每日复盘」编辑当天总结，加入计划、验证结果、关联成交和截图。重开窗口/应用确认内容仍在。
9. 「自选与图表」选择股票或 ETF，查看不复权日 K、MA5/20、买卖点。已下载图表在断网时仍可查看。
10. 用第二台 Mac 选择同一数据目录前，等待 iCloud 下载完成。此项需要实际多设备验证。

## 文件结构

```text
所选数据目录/
  trades/2026.json       成交及删除标记
  reviews/2026.json      每日总结、计划、结果、成交 ID
  market/2026.json       每日市场快照与采集来源/状态
  charts/2026.json       关注证券日 K，按证券和日期合并，不在每日快照中重复存储
  watchlist.json        自选证券
  backups/             最近 30 次修改前的 JSON 备份
```

每种年度文件有 `schemaVersion`、`year`、`entries`；价格和数量等成交数字用十进制字符串。完整持仓从所有年度成交按成交日期、时间和稳定顺序重放。记录文件是原始数据，无 SQLite 依赖。

文件写入使用 NSFileCoordinator、原子替换、写入日志和内容指纹。跨年修改中断后在下次读取时恢复。检测到外部修改、格式错误、iCloud 冲突或未下载文件时，保留原文件并提示，不作为空数据覆盖。

备份恢复重新生成业务年度文件；日 K 为可重建历史缓存，恢复业务备份时保留最新缓存。打开新的数据目录不会合并两套记录；迁移只接受空目标目录。

## 成交与盈亏

- 买入：成本增加成交额与实际费用。
- 卖出：按移动加权平均成本分摊；已实现盈亏为卖出额减费用减对应成本。
- 现金分红：价格栏记录税前总额、数量为 0，实际扣税填税费；净分红计入已实现收益，不降低持仓成本。
- 份额调整：价格为 0，数量为新增/减少份额；总成本保持不变。用于实际送转、拆合，不模拟或自动推测公司行为。
- 买卖成交量允许非整手，便于记录真实零股卖出。股票/ETF 不统一限制 T+1，因为此模块记录实际成交，并非撮合模拟器。
- 卖出成交胜率以每笔卖出为样本，持平计入分母；不是完整交易轮次胜率。
- 市值和浮盈亏按可用行情估值，显示报价日期，缺失行情不以成本或零替代。
- 第一版仅人民币，不支持证券账户隔离、融资融券、债券、港美股。

## CSV 导入

支持 UTF-8（含 BOM）、GB18030、CSV 或制表符文本；支持引号、逗号、换行备注。

必需字段：证券代码、成交日期、买卖方向、成交价格、成交数量。证券名称可选，缺失时显示代码。支持常见别名，例如股票代码、交易日期、操作、成交均价、手续费等。市场和股票/ETF 类型可提供；未提供时按代码推断。

证券代码须保留六位，拒绝把 `1` 自动补成 `000001`。业务类型仅识别明确的买入、卖出、现金分红、份额调整；其他券商业务需人工核对。缺少费用列会提示，不推测税率。成交编号/记录 ID 重复禁止导入，时间/价格/数量相同的疑似重复默认不勾选。选中行整体校验后写入，任何一笔造成卖超或不合法时均不部分导入。

尚未指定实际券商，所以采用常见列名适配，未声称验证过某家券商的专用格式。Excel 的 XLS/XLSX 文件需先另存 CSV；PDF 交割单不自动解析。

## 免费数据与日历

Swift 直接请求腾讯、东方财富公开接口，不附带 Python 环境、不要求密钥、不调用付费服务。参考 AKShare 对上游接口的分类与字段口径。

- 腾讯：指数与证券报价、不复权日 K；最近上证指数日线作为已发生交易日的核对依据。
- 东方财富：涨停/跌停/炸板池、昨日涨停反馈、沪深北涨跌家数、行业/概念涨幅前 100。
- 炸板率 = 炸板家数 /（收盘涨停家数 + 炸板家数）。
- 晋级率 = 昨日涨停样本中今日仍涨停的数量 / 昨日涨停样本数。
- 昨日涨停平均涨幅为样本等权平均，不按成交额或市值加权。
- 板块轮动展示最近五个已保存日期的前十名并集（最多 30 个板块），单日保留前 100 名次。空格代表未取得该读数，不能解释成板块下跌。
- 行情价格、涨跌池、板块排名都有日期核验。无法补采的历史数据保留缺失说明，不写入当前行情冒充过去。
- 上游股票池、市场广度和行业分类的覆盖范围可能不同，来源说明保留这种边界；不把情绪读数包装成预测分数。
- 首次开启自动采集保存最近收盘日。之后每 5 分钟检查、自动请求间隔至少 30 分钟，按北京时间 15:30 后采集；应用未运行时不执行，下次启动最多补采五日，后续轮次继续补齐。免费历史范围有限，手动选择仅支持最近 90 个指数交易日。
- 每个来源独立报告成功/缺失；失败重试一次，后续可再次手动补全。重采集保留手写复盘与原计划；部分来源失败时保留其原读数并标明来自之前的采集。
